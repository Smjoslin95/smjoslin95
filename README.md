### 📡 What I'm building

- **[GroundScape Quantum](https://github.com/Smjoslin95/groundscape-quantum)** — Grover's quantum search applied to conflict-free ground-station scheduling, on a quantum simulator I wrote from scratch in NumPy. [![Try it live](https://img.shields.io/badge/%E2%96%B6_live_demo-0e8a80?style=flat-square)](https://smjoslin95.github.io/groundscape-quantum/)
- **[ScapeOS](https://github.com/Smjoslin95/ScapeOS)** — a full-stack hospitality operations platform (React · Node.js · Express · PostgreSQL · Firebase), built from the ground up.
- **GroundScape** — an operations-coordination platform for ground-based space infrastructure, extending ScapeOS into the space-ops domain.
- - 🧠 **[Migraine Log](https://github.com/Smjoslin95/migraine-log)**: private, local-first migraine tracker with medication overuse alerts (React Native, Expo, TypeScript, SQLite)
